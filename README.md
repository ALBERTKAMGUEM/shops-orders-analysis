# Analyse des commandes et des ventes en restauration

## Présentation du projet

Ce projet de Data Analytics porte sur l'analyse de données de commandes de restaurants issues de **SumUp**.

L'objectif est d'explorer, nettoyer et transformer les données afin de mieux comprendre la structure des transactions et les caractéristiques des commandes.

Ce projet a été réalisé avec **Python et Pandas**, dans le cadre d'un challenge de formation Data Analytics de Le Wagon, puis adapté pour mon portfolio professionnel.

## Objectifs

- Explorer et analyser les données de commandes.
- Nettoyer et préparer les données avec Pandas.
- Relier les données des commandes, des lignes de commande et des établissements.
- Étudier les caractéristiques des transactions.
- Identifier des tendances à partir des données disponibles.

## Technologies et compétences

- **Python**
- **Pandas**
- **Jupyter Notebook**
- **Nettoyage et préparation des données**
